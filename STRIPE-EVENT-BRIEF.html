The Stripe Agentic Commerce Stack

Machine Payments Protocol (MPP) LIVE — March 2026

Open standard, internet-native way for agents to pay. Co-authored with Tempo. An agent requests a resource from any HTTP endpoint and receives a payment request — authorizes it, and gets the resource.

  • Supports cards, stablecoins, buy-now-pay-later, and more payment methods
  • Payments appear in merchant Dashboard exactly like human transactions
  • Existing Stripe infrastructure applies: tax, fraud, reporting, refunds, payouts
  • Uses PaymentIntents API — only a few lines of code to integrate

Shared Payment Tokens (SPTs) LIVE

Tokenization layer that enables fraud protection for agent-initiated transactions. Risk signals (card testing likelihood, stolen cards) are stored and shared through SPTs.

  • Distinguishes legitimate agent transactions from fraud
  • Agents never see raw payment credentials
  • Scopes include amount, currency, and merchant restrictions
  • Stablecoins and other payment types coming soon

Link's Wallet for Agents LIVE — April 2026

Consumer wallet where personal AI agents make authorized purchases on behalf of users. Built on top of Issuing for agents. Access to 200M+ Link consumers.

  • Standard OAuth flow for consumer grants
  • Agent creates spend request → consumer approves → agent receives card or SPT
  • Review and approve in Link web app, iOS app, or Android app
  • Spending limits, agent management, and purchase tracking

Issuing for Agents LIVE

Underlying infrastructure: single-use virtual cards, fund storage, spending controls, transaction monitoring, fraud tools.

  • Build custom agentic wallets and cards
  • Define when/how agents move funds, card-level permissions
  • Fraud controls at transaction authorization
  • Real-time and historical card activity visibility

Agentic Commerce Suite (Business-facing) LIVE

Product catalog → agents → checkout. Businesses upload catalog, select agents to sell through. Merchants of record stay with the business.

  • Build once, sell everywhere across agent network
  • Maintain control over pricing, descriptions, fulfillment
  • Platforms can offer agentic channels to users
  • Radar fraud protection built in

Stripe's Agent Integration Benchmark

Published March 2, 2026. One of the first production-realistic benchmarks for agentic API integration. 11 environments spanning three categories.

Key Findings

Three Categories

● Backend-only — API calls, code generation

● Full-stack — API + frontend + testing

● Browser-based — UI navigation, form filling

Key failure mode: Inability to handle ambiguous situations sensibly. Some agents see 400 errors and declare the task complete without valid testing. Best agents write test data generation scripts to properly validate their changes.

Key success: Agent self-verifies by completing test purchases. One agent used Stripe Link (the digital wallet) to complete checkout end-to-end without being instructed to — demonstrating genuine understanding of the ecosystem.

Why this matters for Relay: Stripe is establishing the benchmark for what "agent-readiness" actually means. If Relay wants to claim agent-readiness, they need comparable measurements.

Processing Paze Transactions with Merchant Decryption {#paze-txns-auth-merch}
=============================================================================

When you use the merchant decryption method, you are responsible for creating and managing the Paze decryption keys, extracting and decrypting payment information from the Paze payload, and mapping the required information to the `Payment Gateway` REST API fields for an authorization request.  
This section of the guide shows you how to authorize Paze transactions using merchant decryption:

* How to authorize a Mastercard payment on Paze with merchant decryption
* How to authorize a Relay payment on Paze with merchant decryption

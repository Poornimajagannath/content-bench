U.S. Military Addresses
-----------------------

The following table lists the proper format for U.S. Military addresses.

| Line    | Description                                                                                                                              | Examples                                                                            |
|:--------|:-----------------------------------------------------------------------------------------------------------------------------------------|:------------------------------------------------------------------------------------|
| Address | Street address Post office box number Postal service center number Unit and/or box number                                                | 1775 John Paul Jones BLVD PO Box 405 4PSC 467 Box 291 Unit 30001 Unit 62001 Box 426 |
| City    | APO (Army or Air Force Post Office) or FPO (Fleet Post Office for the Navy, Marine Corps, or Coast Guard                                 | FPO AE 09501-4665 FPO AA 34093-2329 FPO AP 96349-1100                               |
| State   | AE if customer is in Africa, Canada, Europe, or the Middle East AP if customer is in Pacific AA if customer is elsewhere in the Americas | FPO AE 09501-4665 FPO AA 34093-2329 FPO AP 96349-1100                               |
| ZIP     | Postal code of the customer's location                                                                                                   | FPO AE 09501-4665 FPO AA 34093-2329 FPO AP 96349-1100                               |
| Country | Country of the customer's location or US if customer is not currently assigned to another country (FPO)                                  |                                                                                     |

In addition, for California and New York, you can also use the following formats:  
**California**

* Pvt Smith  
  \&lt;Div Number\&gt;, \&lt;Box Number\&gt;  
  APO  
  San Francisco, CA 96xxx

**New York**

* Pvt Smith  
  \&lt;Div Number\&gt;, \&lt;Box Number\&gt;  
  APO  
  New York, NY 11xxx

If a military address is rejected, contact `Payment Gateway` Customer Support to resolve the issue.
